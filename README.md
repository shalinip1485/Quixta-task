# Responsive Landing Page Redesign

A high-end, minimalist landing page overhaul following a specific Figma design aesthetic. The project features immersive visual elements, smooth animations, and pixel-perfect responsiveness.

## Tech Stack
- **Framework**: Vite + React
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion (motion/react)
- **Icons**: Lucide React
- **Fonts**: Satoshi (Primary), Inria Sans (Logo)

## Setup Instructions
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## Folder Structure
- `src/app`: Main application component and entry point.
- `src/components`: Modular UI components (Header, Hero, ScrollReveal, Footer).
- `src/assets`: Visual assets (Videos, PNGs, SVGs).
- `src/styles`: Global CSS and theme configuration.

## Deployment Instructions
1. Run the build command:
   ```bash
   npm run build
   ```
2. The production-ready files will be in the `dist/` directory.
3. Deploy the `dist/` folder to any static hosting service (Vercel, Netlify, GitHub Pages, etc.).
